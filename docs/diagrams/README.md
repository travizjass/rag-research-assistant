editable; re-export the images whenever the source changes.

## How to view / edit

**Option 1 — open the file**
1. Go to <https://excalidraw.com>
2. Menu (top-left) → **Open** → pick the `.excalidraw` file
   *(or just drag the file onto the canvas)*

**Option 2 — shareable links** (view in any browser, no download)
- Architecture: <https://excalidraw.com/#json=rneLvvY2AuJTs_BetZwbQ,0UpxjQKehXZRJa77iVkwMQ>
- Pipeline: <https://excalidraw.com/#json=yNfhQTvYuBacc_tLopvYK,ct37jtnluoUPcfhVfkcbZA>

## Export as an image (PNG / SVG)

Open the file/link, then **Menu → Export image → PNG or SVG**. Save the PNG
into this folder if you want it to render inline on GitHub.
